# 🎓 Didaktika — Ta'lim Nazariyasi

Pedagogika va Psixologiya fanidan zamonaviy, interaktiv web modul.  
**Meme'lar, animatsiya va hayotiy misollar bilan!**

---

## ✨ Xususiyatlar

- 🎨 **Zamonaviy dizayn**: Glassmorphism, gradient, smooth animations
- 🧠 **Meme bilan o'rganish**: Har mavzuga mos kulgili va esda qoluvchi meme'lar
- 🎯 **Interaktiv elementlar**: 
  - Flip cards (3D animations)
  - Tab system (kategoriyalar)
  - Timeline (tarixiy davrlar)
  - Mini testlar
- 📱 **Responsive**: Desktop va mobile uchun optimallashtirilgan
- ⚡ **Tez va silliq**: React + Vite + Tailwind CSS

---

## 📚 Mavzular

### 01. Didaktikaning Predmeti va Vazifalari
- Didaktika nima?
- Etymology (Yunon tili)
- Hayotdan misol (qurilish analogiyasi)
- 4 ta asosiy vazifa (flip cards)
- Brain evolution meme
- Mini test

### 02. Asosiy Kategoriyalar
- 5 ta kategoriya (interactive tabs):
  - Ta'lim
  - O'qitish
  - Bilim
  - Ko'nikma
  - Malaka
- Distracted boyfriend meme
- Progression visualization
- Mini test

### 03. Tarixiy Davrlarda Didaktik Tizimlar
- 5 davr (vertical timeline):
  - Qadimgi davr (Sokrat)
  - O'rta asrlar (Ibn Sino)
  - Uyg'onish davri (Komenskiy)
  - XIX-XX asr (Pestalotsi, Dyui, Vygotskiy)
  - XXI asr (AI va raqamli ta'lim)
- Har davr uchun meme
- Comparison table
- Mini test
- Completion screen

## 🚀 Ishga tushirish

### 1. Dependencies o'rnatish
```bash
npm install
```

### 2. Development server ishga tushirish
```bash
npm run dev
```

Server `http://localhost:5173/` da ochiladi.

### 3. Production build
```bash
npm run build
```
